# 한국어 TodoList 웹앱 (꼭 해야할 일)

하루의 할 일을 빠르게 추가하고, 완료하고, 정리할 수 있는 깔끔하고 완성도 높은 개인용 TodoList 웹앱입니다.

## 1. 주요 기능

1. **할 일 추가**:
   - `Enter` 키 또는 "추가" 버튼으로 등록
   - 앞뒤 공백 자동 제거 및 빈 문자열/공백만 있는 입력 차단
   - 최대 200자 제한 및 실시간 글자 수 카운터 표시
   - 한글 IME 조합 중(`isComposing`) `Enter`로 인한 중복/의도치 않은 등록 방지
   - 추가 후 입력창 자동 초기화 및 포커스 유지
   - 새 항목은 전체 목록 맨 위에 최신순(`createdAt` 내림차순)으로 추가
   - 현재 필터/검색 조건으로 인해 새 항목이 화면에서 가려질 경우 안내 배너 및 '전체 보기' 제공

2. **완료 상태 관리**:
   - 체크박스 클릭 또는 할 일 텍스트 클릭으로 완료/미완료 토글
   - 완료 항목에 명확한 취소선 및 텍스트 톤 다운(`--color-text-muted`) 적용 (버튼 투명도는 유지하여 가독성 및 조작성 확보)
   - 완료 상태에서도 내용 수정 및 삭제 자유롭게 지원

3. **인라인 내용 수정**:
   - "수정" 버튼 클릭 시 즉시 편집 모드로 전환되고 입력창에 자동 포커스
   - `Enter` 또는 "저장" 버튼으로 저장, `Esc` 키 또는 "취소" 버튼으로 원본 복원
   - 공백만 있는 빈 내용 저장 차단 및 에러 안내
   - 수정 완료 후 수정 버튼으로 키보드 포커스 복귀

4. **개별 삭제 및 실행 취소 (Undo)**:
   - 각 할 일의 "삭제" 버튼 클릭 시 즉시 제거 후 하단에 "할 일을 삭제했어요." 알림 바 제공
   - "실행 취소" 클릭 시 원래 ID, 내용, 완료 상태, 생성일시, 그리고 **원래 목록 위치**까지 완벽하게 복원
   - 빠른 연속 삭제 시 혼란을 방지하기 위해 최신 삭제 1건을 실행 취소 대상으로 명확히 관리
   - 삭제 후 포커스가 사라지지 않도록 인접 항목의 액션 버튼(또는 메인 입력창)으로 안전하게 이동

5. **상태 필터 및 실시간 검색**:
   - "전체", "진행 중", "완료" 탭 필터 (`aria-pressed` 적용)
   - 검색어 입력 시 대소문자를 구분하지 않는 부분 문자열 검색 지원
   - 필터와 검색어는 교집합(AND)으로 결합 적용
   - 검색어 입력 시 우측에 원클릭 초기화(지우기) 버튼 제공
   - '전체 목록 없음', '진행 중 없음', '완료 없음', '검색 결과 없음' 빈 상태를 명확히 구분하여 전용 안내 및 액션 버튼 제공

6. **완료 항목 일괄 삭제 다이얼로그**:
   - 완료된 항목이 있을 때만 버튼 활성화
   - 클릭 시 접근 가능한 확인 모달 다이얼로그(`role="dialog"`) 노출
   - 제목: "완료한 할 일을 삭제할까요?", 본문: "완료한 할 일 N개가 삭제됩니다. 이 작업은 되돌릴 수 없습니다."
   - `Esc` 키 또는 배경(Backdrop) 클릭 시 취소 처리
   - 모달 열림 시 "취소" 버튼에 기본 포커스, 탭 순환 트랩 적용, 닫힐 때 원래 버튼(또는 입력창)으로 포커스 복귀

7. **현황 통계 및 접근 가능한 진행률 막대**:
   - 전체 수, 완료 수, 남은 수 표시
   - 완료율(`0%` ~ `100%`) 계산 (항목이 0개일 때 0으로 나누는 오류 방지)
   - WAI-ARIA 표준 `progressbar` 적용 (`role="progressbar"`, `aria-valuenow`, `aria-valuemin`, `aria-valuemax`, `aria-label`)

8. **데이터 보호 및 자동 저장**:
   - 브라우저 `localStorage` 기반 자동 저장 (`todo-app:v1` 키, 스키마 버전 1 포함)
   - 페이지 새로고침 시 데이터 자동 복원
   - 저장 데이터의 스키마 및 무결성(필드 타입, 필수 값, 날짜 형식, 중복 ID 여부) 엄격 검증
   - 손상된 데이터가 발견되더라도 사용자 데이터를 임의로 지우거나 덮어쓰지 않고 안내 배너 표시
   - 용량 초과 등으로 인한 브라우저 저장 실패 시에도 앱은 메모리 상에서 안전하게 동작을 유지하며 사용자에게 명확히 고지

## 2. 저장 방식 및 제한사항

- **저장 범위**: 본 앱의 모든 데이터는 **현재 사용 중인 웹 브라우저의 로컬 저장소(`localStorage`)에만 저장**됩니다.
- **클라우드 동기화 없음**: 별도의 백엔드 서버, 사용자 계정 로그인, 클라우드 데이터베이스 백업 기능이 포함되어 있지 않습니다.
- **브라우저 캐시 삭제 시 주의**: 브라우저 방문 기록/쿠키/사이트 데이터를 모두 삭제하거나 시크릿 모드를 닫을 경우 데이터가 초기화될 수 있습니다.
- **다중 탭 동기화 제한**: 본 버전은 단일 탭 환경을 기본으로 설계되었으며, 여러 탭에서 동시에 수정할 경우 마지막으로 쓰여진 데이터가 유지될 수 있습니다.

## 3. 기술 스택

- **프론트엔드**: React 18, TypeScript, Vite
- **스타일링**: CSS Custom Properties 기반 디자인 시스템 (`DESIGN.md` 명세 100% 준수)
- **테스트 & 품질**: Vitest, React Testing Library, JSDOM, TypeScript strict mode
- **아이콘**: 외부 의존성 없는 자체 SVG 선형 아이콘 시스템

## 4. 실행 및 빌드 방법

### 요구사항
- Node.js 18 이상 (Node.js 26 호환 검증 완료)
- npm 9 이상

### 개발 서버 실행
```bash
npm install
npm run dev
```

### 테스트 실행 (Vitest)
```bash
npm run test
```

### 프로덕션 빌드 및 프리뷰
```bash
npm run build
npm run preview
```

## 5. 디자인 시스템 및 접근성 가이드

본 프로젝트는 `DESIGN.md`에 명시된 디자인 토큰(`--color-primary`, `--space-*`, `--radius-*` 등)을 엄격히 준수합니다.
- 모바일(360px), 태블릿(768px), 데스크톱(1440px) 반응형 완벽 대응
- 최소 44px 이상의 터치 타깃 영역 확보
- WCAG 2.1 AA 기준 텍스트 명도 대비 4.5:1 이상 충족
- 모든 핵심 기능 키보드 조작 가능 (`Tab`, `Enter`, `Esc`, `Space`)
- `prefers-reduced-motion: reduce` 지원으로 모션 감소 환경 배려
